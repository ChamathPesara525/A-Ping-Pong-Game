#🏓 HTML5 & JavaScript Tennis Game

A modern remake of the classic Pong/tennis arcade game, built with HTML5 Canvas and JavaScript. This project demonstrates interactive gameplay, AI, multiplayer support, menu navigation, sound effects, and polished visuals — perfect for showcasing front-end game development skills.

🎮 Features

Gameplay:

- Player vs AI mode with adjustable difficulty
- Two-player mode with W/S and Arrow keys controls
- Dynamic ball physics with acceleration after paddle hits
- Win condition with first to 3 points
- User Interface
- Interactive menu to select game mode
- Hover-highlighted buttons for intuitive selection
- Display of scores and controls on screen
- Clean and modern canvas graphics with glow and motion trail

Audio Feedback:

- Paddle hit sound
- Wall bounce sound
- Score cheer sound
- Menu click sound
- Win fanfare sound
(All audio files are played using JavaScript Audio objects)

Visual Enhancements:

- Motion blur / trail effect for the ball
- Glow effect on paddles and ball for retro arcade feel
- Responsive score and control display
- Centered messages for win and menu

Code Features

- Keyboard and mouse input handling
- Game loop running at 30 FPS
- Modular functions for drawing, physics, AI, and UI
- AI with adjustable difficulty & error margin
- Supports future expansions like particle effects, background music, or animations

⚙️ How to Play

- Open index.html in a modern browser (Chrome, Firefox, Edge).
- Click a game mode from the menu:
  - Player vs Computer → move paddle with mouse
  - Two Player Mode → Player 1: W/S, Player 2: ↑/↓
- Score by making the ball pass your opponent's paddle.
- First player to reach 3 points wins.
- Click anywhere on the win screen to restart.
